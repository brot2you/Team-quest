# TEAM QUEST v3 — Build better together! · BROT2YOU

Appli de travail de groupe en anglais : 6 rôles, 10 outils, illustrations tirées des fiches imprimables.

## Mise en ligne
Déposer le contenu du dossier dans un dépôt GitHub (index.html + .nojekyll), puis Settings > Pages > branche main.
Fichier unique : images intégrées, aucune dépendance sauf Google Fonts (Lilita One, Nunito), polices de secours prévues.

## Usage en classe
- Une tablette par équipe ; un appareil peut garder plusieurs équipes (une par classe).
- Création : nom, mission, durée, prénoms → rôles tirés au sort (modifiables, rotation d'une séance à l'autre).
- Prisme d'aide et prisme de l'anglais en plein écran : la couleur se voit depuis le bureau du professeur.
- Code professeur (réglages) pour valider les badges.
- « Nouvelle séance » efface les fiches mais garde équipe, mission et badges.

## Données
Stockage local du navigateur (clé teamquest-v3). Export / import JSON dans les réglages.
Les données de la V2 (teamquest-v1) sont reprises automatiquement au premier lancement.

## Limites
- Pas de synchronisation entre appareils (pas de serveur) : le professeur ne voit pas les prismes à distance, il les voit en salle.
- Voix anglaise : dépend du navigateur et de l'appareil.
- Le chrono continue en arrière-plan ; certains navigateurs mobiles peuvent mettre la page en veille si l'écran s'éteint (verrouillage d'écran demandé quand c'est possible).
